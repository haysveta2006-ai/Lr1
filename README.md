# Лабораторная работа №1

**Вариант 1. Класс "ВУЗ"**

## Описание

Программа реализует контейнер `Keeper` для хранения и обработки объектов трёх типов:

- **Student** — студент: ФИО, группа, специальность, курс, средний балл
- **Teacher** — преподаватель: ФИО, группы (которые ведёт), предметы (которые преподаёт)
- **Administrator** — административный персонал: ФИО, должность, телефон, область ответственности

## Возможности программы

- Добавление объектов (студент / преподаватель / администратор)
- Удаление по индексу
- Редактирование по индексу
- Просмотр всех объектов
- Сохранение всех данных в файл
- Загрузка данных из файла
- Обработка исключительных ситуаций

## Технологии

- **Язык**: C++
- **ООП**: наследование, полиморфизм, абстрактные классы
- **Память**: динамическое выделение (`new` / `delete`)
- **STL-контейнеры не используются** (по требованию задания)
- **Среда разработки**: Microsoft Visual Studio 2022
